# Popup as Tab

Popup as Tab converts popup windows into regular tabs in your current browser window.

## Features

- Automatically convert popup windows into regular tabs.
- Add converted tabs to the opener’s tab group when applicable.
- Add exclusions for websites, specific pages, or wildcard URL patterns that should remain as popup windows.
- Configure where converted popups and new tabs appear. Converted popups can stay in their original order or appear next
  to the opener, while new tabs can open next to the current tab or in the browser’s default position.
- Press `Alt+T` to open and activate a new tab at the far right of the current window, even when new tabs normally
  open next to the current tab. To check or change the shortcut, visit `chrome://extensions/shortcuts` in Chrome or `edge://extensions/shortcuts` in Edge.

## Permissions

- `alarms`: clears temporary diagnostic badges after a set time, even if the service worker restarts.
- `storage`: saves the enabled state, placement preferences, exclusion rules, diagnostics, and session state.
- `tabs`: identifies, reads, moves, orders, activates, and groups popup and New Tab pages.
